# Homepage artwork

Original Canva illustration generated specifically for Christopher Meiklejohn’s research-into-practice homepage. A research workshop connects to an inhabited production city. Canva media: `MAHYzYWlYi4` (1776 × 896 original PNG). `research-to-production.webp` is its compressed website copy.

The site does not reuse the storybook backgrounds or pixel illustrations. The animated network is native canvas code, runs locally, supports pause and reduced motion, and has no interaction with hiring/contact links or page text.

## Shared site identity

`css/site-theme.css` owns the site's shared palette, fonts, header, navigation,
footer, and reading measure. `css/home.css` only composes the homepage. The
palette follows Filibuster.cloud and Little Worlds, Big Ideas: midnight navy
`#080b21`, cyan `#6de0f6`, warm cream `#faf7ee`, violet `#505493`, and coral
`#f29783`. The print CV uses dark navy and violet accents on white paper.
Artwork remains original to this homepage; no Storybook background is reused.

The network canvas and its motion control live in the shared default layout.
Content stays on opaque backgrounds; animation is a quiet detail in the margins.

## Presentation rule

Prefer graphics that carry the explanation. Research journeys show authorship,
implementation, adoption, and feedback into new research; industry drawings
show the kind of system or engineering contribution. Keep claims and sources
in real text beside each drawing. Drawings are explanatory illustrations, not
benchmarks, official company logos, or claims of a completed formal proof.
Keep these sections open, without enclosing cards or large boxes.
