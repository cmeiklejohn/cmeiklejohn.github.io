# Homepage artwork

Original Canva illustration generated specifically for Christopher Meiklejohn’s research-into-practice homepage. A research workshop connects to an inhabited production city. Canva media: `MAHYzYWlYi4` (1776 × 896 original PNG). `research-to-production.webp` is its compressed website copy.

The site does not reuse the storybook backgrounds or pixel illustrations. The animated network is native canvas code, runs locally, supports pause and reduced motion, and has no interaction with hiring/contact links or page text.
